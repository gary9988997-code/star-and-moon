# 星往月来

生日惊喜网站骨架 · Next.js 14 + TypeScript + Tailwind CSS + Framer Motion

## 页面

| 路由 | 名称 |
|------|------|
| `/gate` | 月光之门 |
| `/` | 星空首页 |
| `/constellation` | 星图航线 |
| `/letters` | 月光信局 |
| `/vow` | 月下定信 |

## 开发

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)
